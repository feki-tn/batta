# بتة - Auction Web Application
# Prototype Version
## Description

بتة is an auction web application built using Java, Servlet, and a MySQL database. The system allows users to register, list auctions, place bids, and manage their profiles. Admin users have additional privileges, such as managing auctions and user data.

This project was created for educational purposes and showcases a complete CRUD functionality for an auction platform.

## Features

- **User Authentication**: Login, Signup, and Session-based authentication.
- **Auction Listings**: Users can create and manage their listings, view other auctions, and place bids.
- **Admin Panel**: Admin users can manage users and listings.
- **Bid Management**: Users can place bids, see the highest bid, and view auction details.
- **Timers**: Auctions have a countdown timer that triggers when the auction ends.
- **Database**: MySQL used to store user data, listings, bids, and auction details.

## Technologies Used

- **Frontend**: HTML, CSS (Custom Styling), and JavaScript for client-side functionality.
- **Backend**: Java Servlets, JDBC, and MySQL for database operations.
- **Database**: MySQL for storing data about users, listings, bids, and auctions.



### Prerequisites

- **Java**: Ensure that Java 8 or above is installed on your machine.
- **MySQL**: You need a running MySQL database instance.
- **IDE**: Recommended IDEs for Java development are Eclipse or IntelliJ IDEA.
- **Apache Tomcat**: Servlet container to run the Java web application.
